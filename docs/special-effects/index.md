# Special Effects

There are a few special effects that the shorthand supports. These sounds are represented by the effect name encapsulated by **_--_** , like **_--effectname--_** . Some of these will be affected by modifications as they are created with SSML and TTS, if so it will be noted. Plans for the future is to allow streamers to add their own sounds to this system. These are all case insensitive.
