# _Tones_
The following cheat sheet uses the old one character system, if you use it make sure to translate it to the two character system. So #expixx instead of #epxx.

This is a cheat sheet on how to create tone sounding sounds by using the Expletive/Beep tag, that was created by a community memeber [Nowrench](https://linktr.ee/nowrench).
